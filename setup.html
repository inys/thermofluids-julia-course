Software Setup

1 Julia Installation

Install Julia from:

https://julialang.org/downloads/

Recommended version:

julia --version

Use Julia 1.10 or newer if possible.

2 Development Environment

Recommended options:

  1. VS Code with the Julia extension
  2. Pluto notebooks
  3. Jupyter notebooks via IJulia
  4. Julia REPL

3 Basic Package Installation

using Pkg

Pkg.add([
    "Plots",
    "CairoMakie",
    "LinearAlgebra",
    "SparseArrays",
    "Statistics",
    "DifferentialEquations",
    "OrdinaryDiffEq",
    "DataFrames",
    "CSV"
])

4 FEM Packages

using Pkg

Pkg.add([
    "Gridap",
    "GridapGmsh",
    "Gmsh"
])

7 Test Installation

using DifferentialEquations
using Plots

f(u,p,t) = -0.01u
prob = ODEProblem(f, 1.0, (0.0, 10.0))
sol = solve(prob)

plot(sol)

If a plot appears, the basic installation works.
